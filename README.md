# 3C 生物基礎 第3回テスト対策

3年総合クラス向けの通常学習用Webアプリです。

## 主な機能

- 免疫分野の全30問
- 10問・20問・全30問から出題数を選択
- 回答直後に正誤と解説を表示
- 選択肢を毎回シャッフル
- 間違えた問題だけを復習
- 途中経過と復習記録を端末のブラウザ内に保存
- 問題図をHTML内に収録

## GitHub Pagesでの公開

リポジトリの `Settings` → `Pages` で、`Deploy from a branch`、`main`、`/(root)` を選択して保存します。

## 注意

学習記録は利用した端末・ブラウザ内に保存されます。別の端末やブラウザには自動的に引き継がれません。
